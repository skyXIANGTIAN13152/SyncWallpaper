# 壁纸事务

屏序通过 Windows `IDesktopWallpaper` 为每块活动显示器设置静态壁纸。事务开始时读取当前壁纸快照，随后按目标屏幕尺寸渲染、设置并回读验证。

支持 JPG/JPEG/PNG/BMP。特定组合支持 Fill、Fit、Stretch、Center、Tile 和 Span；通用组合支持前五种单屏方式。Span 会修改 Windows 全局位置模式，因此通用组合在保存及应用前均拒绝它，以免影响未分配的屏幕。缓存键包含原图哈希、目标尺寸、填充方式、背景色和渲染版本，并受容量上限约束。

规则：

- 特定组合存在歧义、弱身份证据或配置不完整时不写入。通用组合使用明确的位置规则，不需要硬件身份评分。
- 通用事务要求横屏数量、竖屏数量分别与整套配置完全一致，手动应用也一样；每个方向的需求数量取最高保存编号，没有该方向位置则为 0。数量多、少或横竖构成不同都不会部分套用。通用组合不设置数量上限，不会为编号空缺展开大量占位记录。
- 数量完整匹配后，只渲染、写入和回读验证已选择壁纸的位置，成功数量以本次写入目标数计算。未选壁纸及编号空缺位置保留当前壁纸；这些屏幕仍必须参与整套数量及布局检查。无任何可应用目标时不报告成功。
- 匹配时克隆全体活动屏幕作为内存布局快照。创建事务目标时按快照重新匹配组合，拒绝缺少整套快照、数量不符或映射已被改动的结果。
- 在首次写入前、逐屏应用及重试时、最终验证时，核对 Windows 返回的整套设备路径集合和各屏幕边界（位置、宽度、高度）。即使未选壁纸的屏幕发生插拔、横竖变化或移动，也会使旧布局失效；首次写入前发现变化则保持原壁纸，已经写入后发现变化则停止并尝试回滚本次改动。
- 缺失图片和不属于当前活动路径的目标保持原壁纸。
- 已经是目标路径时不重复设置。
- Explorer COM 暂不可用时进行有限重试。
- 任一已写入屏幕回读失败或通用布局发生变化时，按逆序尝试恢复本次事务中已改动屏幕的原壁纸，并记录恢复结果。
- 不把黑色纯色或不存在的备用图片当成兜底。
- 事务快照只存在于内存，不生成磁盘回滚备份。
