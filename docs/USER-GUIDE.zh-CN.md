# 屏序 1.2 壁纸专版使用指南

1. 启动 `App\SyncWallpaper.App.exe`。关闭窗口后程序会留在系统托盘继续监测。
2. 在“显示器识别”查看当前屏幕。这里会完整显示厂商、产品、序列号/设备路径、接口、分辨率、刷新率、DPI、HDR、方向/翻转和桌面坐标，但不会修改这些参数。
3. 若同型号显示器无法唯一识别，点击“显示 A/B/C”，在每块屏幕上确认临时字母并绑定逻辑角色。字母不是永久编号。
4. 在“壁纸档案库”导入 JPG/JPEG/PNG/BMP。删除磁盘文件后点击“刷新档案库”，不存在的条目会隐藏。
5. 在“壁纸组合”保存当前特定显示器组合，或先新建空白组合再编辑。特定组合需要为每个角色选择屏幕、壁纸和填充方式。组合可以重命名、删除和手动应用；删除组合不会删除壁纸原图。
6. 要给陌生显示器组合准备默认壁纸，点击“新建通用组合”，从 0 块横屏、0 块竖屏开始，点击“添加横屏”或“添加竖屏”，为横屏1、横屏2、竖屏1等位置选择或导入壁纸。通用位置数量不设上限。可以先保存空白组合，以后继续编辑；空白或完全没有选择壁纸的组合不会应用。
7. 横屏和竖屏各自按桌面位置从左到右、同列从上到下编号，包含笔记本屏幕。每个方向的最高编号就是该方向所需的屏幕数量，未添加的方向要求为 0 块。删除某位置不会改变其他编号：例如只保留横屏1、横屏3，仍然需要 3 块横屏，横屏2保留当前壁纸。重新添加会补上最小空缺编号；选择“保留当前壁纸”的位置也会保留原壁纸。
8. 开机或显示器组合变化后，自动匹配优先使用完整且安全识别的特定组合，找不到时才检查通用组合。当前横屏数量和竖屏数量必须分别与通用组合完全一致，才能整套应用；例如要求 2 横屏的组合不能用于 1 横屏 + 1 竖屏。多套通用组合只在数量完全匹配、已启用且已配置壁纸的组合中按优先级选择。既没有安全完整的特定匹配，也没有符合条件的通用匹配时，所有屏幕保持当前壁纸。通用组合不支持“跨区”填充方式。
9. 可点“应用选中组合”手动使用选中的通用组合，包括当前已有特定匹配时；手动应用同样要求横屏和竖屏数量分别完全一致，不能绕过数量检查。下一次自动检测仍遵循特定组合优先的规则。
10. “设置”可控制自动匹配、开机自启、低资源模式和手动更新检查。托盘菜单可打开主界面、重新检测、重新应用、暂停/恢复自动匹配和退出。

特定组合成功匹配时显示“已匹配”；通用组合显示“通用匹配”“后备待用”“未配置”或“数量不符”。“数量不符”表示当前横屏或竖屏数量与该组合的要求不一致，整套组合不会应用；编辑器会同时显示所需数量和当前连接数量。通用壁纸成功应用后，托盘显示古金双屏轮廓与暖白菱形；正在识别、暂停和错误状态会优先显示，避免把未完成应用误认为通用匹配成功。

默认外观为深墨绿、古金和暖白的“秘境”主题，可在设置中切换主题。各页标题和操作按钮固定，鼠标滚轮只滚动下方内容；档案库搜索框和组合筛选、选中组合操作同样保持可见。

标准发行版的数据默认位于解压或安装根目录下的 `Config`、`Wallpapers`、`Cache`、`Thumbnails` 和 `Logs`；目录不可写时回退到 `%LocalAppData%\SyncWallpaper`。可在设置页查看实际数据目录。程序不创建配置历史备份或壁纸回收备份。
