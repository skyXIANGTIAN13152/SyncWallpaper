# 屏序 1.1 壁纸专版使用指南

1. 启动 `App\SyncWallpaper.App.exe`。关闭窗口后程序会留在系统托盘继续监测。
2. 在“显示器识别”查看当前屏幕。这里会完整显示厂商、产品、序列号/设备路径、接口、分辨率、刷新率、DPI、HDR、方向/翻转和桌面坐标，但不会修改这些参数。
3. 若同型号显示器无法唯一识别，点击“显示 A/B/C”，在每块屏幕上确认临时字母并绑定逻辑角色。字母不是永久编号。
4. 在“壁纸档案库”导入 JPG/JPEG/PNG/BMP。删除磁盘文件后点击“刷新档案库”，不存在的条目会隐藏。
5. 在“壁纸组合”保存当前组合，或先新建空白组合再编辑。组合可以命名、重命名、删除和手动应用；删除组合不会删除壁纸原图。
6. 每个角色选择对应壁纸和填充方式，保存后确认组合显示绿色“已匹配”。红色“未匹配”表示身份、屏数、角色或壁纸仍不完整。
7. 开机或显示器组合变化后，屏序会自动检测并应用匹配组合，无需手动点击。
8. “设置”可控制自动匹配、开机自启、低资源模式和手动更新检查。
9. 托盘菜单可打开主界面、重新检测、重新应用、暂停/恢复自动匹配和退出。

正式 D 盘版本的数据位于 `D:\屏序 SyncWallpaper\Config`、`Wallpapers`、`Cache`、`Thumbnails` 和 `Logs`。程序不创建配置历史备份或壁纸回收备份。
