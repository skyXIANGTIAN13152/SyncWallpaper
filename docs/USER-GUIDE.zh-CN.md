# 屏序 SyncWallpaper Beta 1.0.0 使用指南

1. 启动 `SyncWallpaper.App.exe`。默认是轻量模式，任务栏、Shell、远程和在线壁纸不会启动。
2. 在“观测档案库”导入 JPG/JPEG/PNG/BMP 图片。
3. 在“显示器配置”查看稳定身份来源；需要区分同型号屏幕时点击“显示器识别”，各屏会短暂显示 A/B/C。A/B/C 只用于本次确认，不会保存成永久编号。
4. 在“规则与匹配”中输入档案名称并点击“保存当前壁纸组合”。每套档案会独立保存显示器稳定身份、逻辑角色和对应壁纸；可以保存多套同屏数或不同屏数的组合，也可以重命名、删除或应用选中的组合。删除组合不会删除壁纸文件。
5. 插拔 HDMI/DP/USB-C、改变拓扑或恢复 Explorer 后，屏序会等待拓扑稳定再应用；歧义时保持现状并提示确认。
6. “设置 → 按需模块”可切换轻量、标准、完整或自定义模式。关闭模块会显示失去的功能与资源状态。
7. “诊断实验室”先执行只读检查，再导出脱敏报告。危险操作不会在后台自动执行。

8. “设置 → 更新检查”默认关闭联网。点击“检查更新”只查询 GitHub Release，发现新版本后点击“前往 GitHub Release”由你自行下载和安装；也可以主动开启每周自动检查。

数据优先保存在可写的程序/项目目录（例如 `D:\屏序 SyncWallpaper`）中的 `Wallpapers`、`Config`、`Cache` 和 `Logs` 文件夹；目录不可写时才使用 `%LocalAppData%\SyncWallpaper`。设置页会显示实际目录。首次切换到 D 盘目录时会自动迁移旧库，屏序不会自动下载或安装更新，不上传壁纸、显示器身份、配置或日志。
