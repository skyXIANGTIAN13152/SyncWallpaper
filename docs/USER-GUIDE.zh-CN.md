# 屏序 SyncWallpaper Beta 1.0.0 使用指南

1. 启动 `SyncWallpaper.App.exe`。默认是轻量模式，任务栏、Shell、远程和在线壁纸不会启动。
2. 如需副屏任务栏，在“任务栏与屏幕行为”点击“启用副屏任务栏”。它只在非主显示器显示：单窗口按钮可激活/恢复或再次点击最小化；多窗口应用会显示分组菜单；右键可逐窗口关闭或固定应用；悬停约 0.36 秒显示实时预览。固定项在所有副屏共享，保存在 `Config\taskbar-pins.json`。
   - “自动隐藏”开启后，鼠标离开约 0.65 秒会把任务栏收到底边，只保留 2 px 唤醒区域；菜单或预览打开时不会收起。自动隐藏不会永久缩小 Windows 工作区。
   - “预留工作区”只在非自动隐藏模式生效。恰好一块副屏时使用 Windows AppBar 协商；多块副屏若 Shell 无法可靠逐屏预留，会显示安全降级原因并使用覆盖模式，避免把多个缩进错误叠到同一屏幕。
   - 点击“关闭副屏任务栏”后，独立进程、AppBar、Hook、Timer、时钟和缩略图随即退出。
3. 在“观测档案库”导入 JPG/JPEG/PNG/BMP 图片。
4. 在“显示器配置”查看稳定身份来源；需要区分同型号屏幕时点击“显示器识别”，各屏会短暂显示 A/B/C。A/B/C 只用于本次确认，不会保存成永久编号。
5. 在“规则与匹配”中输入档案名称并点击“保存当前壁纸组合”。每套档案会独立保存显示器稳定身份、逻辑角色和对应壁纸；可以保存多套同屏数或不同屏数的组合，也可以重命名、删除或应用选中的组合。删除组合不会删除壁纸文件。
6. 插拔 HDMI/DP/USB-C、改变拓扑或恢复 Explorer 后，屏序会等待拓扑稳定再应用；歧义时保持现状并提示确认。
7. “设置 → 按需模块”可切换轻量、标准、完整或自定义模式。关闭模块会显示失去的功能与资源状态。
8. “诊断实验室”先执行只读检查，再导出脱敏报告。危险操作不会在后台自动执行。

9. “设置 → 更新检查”默认关闭联网。点击“检查更新”只查询 GitHub Release，发现新版本后点击“前往 GitHub Release”由你自行下载和安装；也可以主动开启每周自动检查。

数据优先保存在可写的程序/项目目录（例如 `D:\屏序 SyncWallpaper`）中的 `Wallpapers`、`Config`、`Cache` 和 `Logs` 文件夹；目录不可写时才使用 `%LocalAppData%\SyncWallpaper`。设置页会显示实际目录。首次切换到 D 盘目录时会自动迁移旧库，屏序不会自动下载或安装更新，不上传壁纸、显示器身份、配置或日志。
