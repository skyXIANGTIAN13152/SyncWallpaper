# 故障排查

## 开机后壁纸保持原状

查看主程序日志和最近一次壁纸事务状态。Ambiguous、Unknown、缺失壁纸、Explorer 不可用或回读失败都会保持原壁纸，并要求重新识别，不会猜测。

## 显示器身份变成需要确认

同型号且无可用序列号时这是预期的安全行为。打开“显示器识别”，在每个屏幕确认 A/B/C，再保存 Laptop、Landscape 或 Portrait 逻辑角色。

## 外接屏暂时不可用

不要手动设置黑色背景作为替代。TopologyCoordinator 会等待稳定状态并取消过期事务；Explorer/COM 暂时不可用时采用退避重试。物理拔插完成后可点击“重新检测”。

## 模块出现 Faulted

核心壁纸服务和配置不会因独立宿主故障退出。设置页会显示状态、PID、内存、CPU、句柄、依赖和最近错误；重复故障的模块会自动禁用，可在确认原因后重新启用。

## 配置损坏

ConfigurationStore 会按当前文件、.bak、.bak.1… .bak.4 回退。不要删除 Backups；先导出脱敏诊断，再从恢复点手动恢复。
