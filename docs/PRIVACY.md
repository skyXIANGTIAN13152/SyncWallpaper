# Privacy

SyncWallpaper Beta is offline by default. It does not contain telemetry, analytics, advertising or online wallpaper downloads. Display identity data, wallpaper paths, audio endpoint IDs and diagnostics stay in the local data directory unless the user exports a report.

Logs are local, rotated at 1 MiB per file and retained for seven days. Reports should be reviewed before sharing: paths, monitor serials, device instance names and profile notes can identify a machine. The application does not elevate and does not modify other startup entries.
