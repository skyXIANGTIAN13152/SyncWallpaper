# 隐私

屏序没有遥测、分析、广告、远程控制或在线壁纸提供器。

新安装默认启用每日更新检查；升级保留已有开关，可在设置中关闭。自动检查或手动点击“检查更新”会访问官方公开 GitHub Releases API。只有用户确认更新后，才下载该发布的 ZIP 和 SHA-256 校验文件。GitHub 及其下载服务会收到普通网络请求包含的 IP 地址和应用版本等请求头；程序不会上传显示器身份、序列号、设备路径、壁纸、配置、日志、用户 ID 或设备指纹。

配置、壁纸、缓存和日志保存在设置页显示的数据目录。日志会脱敏用户目录；导出的显示器报告对硬件身份字段使用一致性哈希。分享诊断文件前仍应人工检查内容。

程序不请求管理员权限，只管理自身当前用户启动项，不修改其他软件或系统服务。
