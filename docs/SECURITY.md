# 安全边界

- 显示器 API 只读。项目不调用 `SetDisplayConfig` 或 `ChangeDisplaySettingsEx` 修改显示参数。
- 壁纸只应用到当前活动且已唯一匹配的 monitorDevicePath；歧义、弱身份、缺失资产或验证失败均保持现状。
- 配置文件名禁止路径穿越，JSON 最大 10 MiB、最大深度 32；保存使用临时文件、磁盘刷新和原子替换。
- 不生成配置历史或壁纸删除备份。用户确认更新后会使用受限临时目录保存新程序与替换失败时的旧程序恢复文件。
- 新安装默认每天访问官方 GitHub Releases 检查更新，已有开关在升级时保留；可关闭自动检查。元数据请求使用 HTTPS、15 秒超时、取消令牌和 2 MiB 响应上限。
- 浏览器只允许打开配置仓库的 `https://github.com/.../releases/` 页面；Release Notes 只显示为限长纯文本。
- 更新下载与安装必须先得到用户确认。仅接受官方仓库的对应版本和架构发行包，并核验 SHA-256、包清单与解压路径。程序只替换发行组件，保留 `Config`、`Wallpapers`、`Cache`、`Thumbnails`、`Logs` 和其他运行数据。
- 更新助手从独立临时位置按需运行，等待主程序退出后执行替换，遇到替换失败时尝试恢复旧程序；它不常驻，不执行包内脚本，不请求管理员权限。
- 当前发行包未签名；同一 GitHub Release 提供的 SHA-256 用于检验传输完整性，不能替代独立代码签名或抵御官方仓库被控制的情形。
- 不加载插件、不注入 Explorer、不创建额外功能宿主或系统服务。
- 日志与只读诊断默认保存在本机，不自动上传。

安全问题请通过 GitHub Security Advisories 私下报告，不要公开粘贴原始设备路径、序列号、日志或配置。
