# 阶段 2：独立副屏任务栏 v3 报告

日期：2026-08-10  
状态：Implemented；当前 Windows 11 三屏真实门禁通过，但仍不是完整的 Explorer/DisplayFusion 任务栏，也未达到 Verified。

## 已实现能力

- `SyncWallpaper.TaskbarHost` 继续由 `SyncWallpaper.Host.exe --module TaskbarHost` 独立承载。轻量模式默认不启动；关闭模块后副屏条、Hook、Timer、DWM 缩略图和独立进程全部退出，壁纸核心继续运行。
- 每个非主显示器建立一条无激活、Topmost、工具窗口式 WPF 副屏条。混合 DPI 按 Windows 显示设备名映射原生工作区，并以原生像素定位；负坐标和同型号无序列号显示器使用独立运行键，不把临时几何保存为硬件身份。
- 枚举并过滤真实 Win32/UWP 任务窗口，排除隐藏、cloaked、Shell、owner、工具窗、无激活和本进程窗口；单个受保护或瞬时消失的窗口不会中断整次刷新。
- 任务按 AppUserModelID、进程路径、进程名、窗口类名依次分组。单窗口按钮直接激活、恢复或最小化；多窗口组显示数量并打开逐窗口菜单。
- 逐窗口菜单可切换、最小化或发送标准 `WM_CLOSE` 关闭请求。普通权限不会强杀进程，也不会绕过 UIPI；高权限失败返回 AccessDenied。
- 鼠标悬停 360 ms 后按需创建 DWM 实时缩略图；保持源窗口宽高比，并限制在当前显示器工作区。离开按钮、打开菜单或关闭模块时立即注销缩略图。
- 运行中的应用可以固定到副屏任务栏。固定项按 AppUserModelID 或有效可执行文件路径保存到 `Config\taskbar-pins.json`，原子写入且不生成历史备份；已关闭应用可再次启动，失效路径不会执行。
- 固定项当前为所有副屏共享；固定/取消固定后所有副屏条同步刷新。右侧时钟显示本地时间和日期，并由现有低频刷新周期更新。
- 设置页可独立选择自动隐藏和工作区预留。自动隐藏使用可测试的延迟状态机，鼠标离开后收起到 2 px 底边唤醒区域；菜单或 DWM 预览打开时保持可见，且不争用 Explorer 的自动隐藏 AppBar 槽。
- 单副屏普通模式使用公开 AppBar API 协商工作区，并在宿主停止时注销。当前机器发现多个底边 AppBar 可能被 Windows Shell 叠加到同一副屏，因此多副屏会报告安全降级并使用覆盖模式，不修改任何显示器工作区，也不采用全局 `SPI_SETWORKAREA` 绕过。
- WinEventHook、显示设置/用户首选项事件和 5 秒兜底共同处理窗口及拓扑变化。Explorer PID 变化会重建快照，但模块不注入、不替换 Explorer。
- IPC 状态包含显示器数、副屏条数、任务数，以及每条副屏条的任务数、分组数、固定项数、坐标、自动隐藏/隐藏状态、工作区预留状态和最近位置降级原因。状态改变无需等待 5 秒兜底即可上报。

## 自动与真实验证

- `TaskbarHostTests`：20 个专用测试。除窗口过滤、UWP、负坐标、最大交叠、同型号双屏、动作、防抖、停用清理、Hook 失败和 Explorer PID 恢复外，还覆盖分组键/前台预览选择、固定项原子持久化、无效路径拒绝、缩略图比例/边界、自动隐藏延迟/唤醒、负坐标隐藏位置和工作区预留策略。
- 全套默认结果：203 个通过、0 个失败、4 个按设计 Skip（178 单元 + 9 更新 + 16 集成）。四个 Skip 分别是两项真实任务栏门禁、桌面 Shell 和真实 CCD 门禁。
- `SYNCWALLPAPER_REAL_TASKBAR_TEST=1`：当前 Windows 11 三屏会话 2/2 通过。普通模式验证恰好创建两条副屏任务栏、每条位于对应副屏、IPC/资源/安全降级与退出；自动隐藏模式验证两条任务栏按延迟收起、实时状态更新、不改变工作区并在 stop 后退出。
- Release 构建：0 个警告、0 个错误。

## 已知限制

- AppBar 工作区预留目前只在恰好一块副屏时启用；多副屏因当前 Windows Shell 逐屏归属实测不可靠而安全回退为覆盖模式，可能覆盖最大化窗口底部 48 px。
- 自动隐藏目前固定在副屏底边，尚无左/上/右边缘、动画速度和逐屏独立设置。
- 固定项只覆盖本地 EXE 与 AppUserModelID 的基础启动，不支持 ShellLink 参数、工作目录编辑、拖放排序、每显示器独立固定集或 Jump List。
- 分组菜单与 DWM 单窗口预览已实现，但没有类似 Explorer 的多缩略图横排、拖动重排和进度叠加图标。
- 尚无通知区域镜像、可视布局编辑器和完整时钟自定义。公共 Windows API 不提供稳定的第三方通知图标枚举，因此不会通过 Explorer 注入或内部工具栏读取冒充实现。
- UWP 和高权限路径已有模型/自动测试，但真实样本仍不足。
- Explorer PID 变化只有模拟恢复证据；没有强制结束用户的真实 Explorer。Windows 10、睡眠唤醒、HDR 全屏和长时间运行仍未验证。

下一步优先完善每显示器固定项、拖动排序与 Jump List 的安全实现；完整通知区域镜像继续受公共 API 边界限制。在真实 Explorer 重启和 Windows 10 门禁通过前，本模块保持 Implemented，不提升为 Verified。
