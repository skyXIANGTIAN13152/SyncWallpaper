# 屏序 SyncWallpaper 界面规范

当前默认主题为用户审核通过的「秘境」。程序窗口、编辑器、弹窗、软件图标和托盘保持同一套视觉语言。

## 颜色与文字

| 用途 | 颜色 |
|---|---|
| 窗口底色 | 深墨绿 `#0D1C19` |
| 阅读表面 | 林绿 `#142722` |
| 主要操作和描边 | 古金 `#D2B47A` |
| 主要文字和高光 | 暖白 `#F3EBDC` |
| 辅助文字 | 苔灰 `#A5B5A9` |
| 异常提示 | 柔铜 `#D5A085` |

中文优先使用 Microsoft YaHei UI。正文维持清晰的字号和对比度；身份信息、长路径和说明允许换行或通过工具提示完整查看。状态同时使用文字和符号表达。

AppThemeCatalog 定义语义颜色。为了兼容原窗口的资源引用，Cyan、Blue、Purple 资源名仍然存在，但在秘境主题中分别表示古金、苔白、暖金。旧主题作为可选项保留。

## 背景与控件

MysteryBackdrop 使用静态 WPF 矢量绘制雾光、月蚀光环、星轨和少量星点。没有背景动画、计时器、联网素材或修改桌面壁纸的行为。输入框、下拉菜单和阅读区使用独立深色表面，保证内容不被背景干扰。

Themes/Controls.xaml 统一按钮、主操作、输入框、下拉选项、复选框、开关、列表选中、提示和滚动条。所有交互控件有可见键盘焦点。关闭下拉框时保留鼠标滚轮向外层页面传递的行为。

## 页面结构

七个主页面均使用固定顶部与独立内容区：标题、说明和页面级操作保留在顶部，只有下方内容滚动。档案库的搜索框与组合筛选、选中组合操作同样固定；列表内的单项编辑、图片预览仍随所属内容显示。长正文弹窗固定标题和底部按钮，正文独立滚动。

- 概览以真实显示器位置与壁纸为中心，下方展示实际匹配依据和最近结果。
- 显示器识别保留完整只读身份与几何信息。
- 壁纸档案库使用现有文件生成缩略图，不导入提案中的示意壁纸。
- 壁纸组合区分特定与通用匹配；屏幕数量与匹配状态直接可见。
- 组合编辑器显示每个位置的壁纸预览、适应方式和匹配需求，保留原身份选择与规则说明。
- 运行记录、设置、关于和确认弹窗复用相同配色、间距及控件样式。

通用组合仍按横竖方向最高编号分别计算所需数量。删除中间槽位不会给其余槽位重新编号；空缺或未选壁纸的位置保留当前壁纸。外观更新不改变匹配策略。

## 图标

BrandGlyph、assets/syncwallpaper-icon.svg 与 assets/AppIcon.ico 使用横屏、竖屏及悬空菱形，内部透明，没有圆形实心背板。

托盘沿用双屏轮廓，以勾、菱形、短横、暂停双线和感叹号区分特定匹配、通用匹配、未匹配、暂停和异常；正在识别仍保留独立过渡状态。运行时只在状态变化时重新生成图标。

任务栏与托盘均提供多个像素尺寸的 ICO。通过 tools/BuildTrayIconAssets.ps1 重新生成静态资源。历史参考图片留作原始素材，不再参与产品图标生成。

## 数据与验证

外观偏好单独保存在 settings.json 的 uiTheme 字段。升级不重建、不清空组合或壁纸库；界面缩略图只读取已有文件。自动测试覆盖颜色对比、主题切换、中文输入布局、滚轮行为和图标状态。发布前使用隔离数据验证真实窗口，随后比对原始组合和壁纸文件校验值。
