# 现有功能优化报告

日期：2026-08-09  
范围：只优化已有显示器识别、壁纸组合、后台资源和数据管理，不新增大型功能，也不改变现有视觉风格。

## 已解决问题

1. **显示器身份不会被无效 ContainerId 覆盖**：全零、全 `F` 和已知占位 GUID 会被拒绝；旧档案启动时迁移到身份模型 V3，并按 EDID 序列号、设备路径、WMI InstanceName、硬件拓扑的可靠顺序重建指纹。
2. **多屏数量不会抬高置信度**：组合置信度改为整套组合中最弱角色的证据强度。三个只有几何信息的屏幕不会因为分数相加而达到自动应用门槛。
3. **弱证据不自动猜测**：ContainerId 和分辨率/方向/桌面坐标只用于提示与候选排序；没有强证据时返回待确认，保留当前壁纸。
4. **组合“应用”和“编辑”分离**：手动应用档案不会修改编辑选择、优先级或修改时间。显示器拓扑变化后仍会自动匹配；成功匹配单独记录为最近匹配档案。
5. **隐藏窗口不反复重绘**：窗口隐藏到托盘时只合并记录一次待刷新状态，再次显示时统一刷新，避免后台事件触发整页 UI 重建。
6. **WMI 资源及时释放**：显示器补充信息查询显式释放结果集和每个对象，不依赖垃圾回收器延迟回收句柄。
7. **轻量模式真正影响资源**：停用装饰性背景光效，壁纸渲染缓存限制为 128 MiB；其他模式为 512 MiB，缓存按最近使用时间淘汰。
8. **不再生成配置历史备份**：配置仍采用临时文件写入、刷盘和原子替换以避免半写文件，但遵循当前产品选择，不建立回滚历史。用户主动删除壁纸的软删除区不受影响。
9. **桌面快捷方式能唤醒现有实例**：开机后台运行时，再次点击桌面快捷方式会向主实例发送激活请求并打开已有窗口，不再静默退出或创建第二个进程。
