# 阶段 1：窗口区域与组合编辑报告

日期：2026-08-09  
状态：Implemented（尚未达到 Tested / Verified）

## 本轮结果

- Window Engine 新增五种按显示器保存的区域预设：左右二等分、横向三等分、上下二等分、四宫格、主区 + 双副区。
- 区域使用 0–1 标准化坐标保存，因此分辨率变化和负桌面坐标不会直接使旧布局失效。
- 显示器绑定复用现有分层身份匹配。序列号、设备路径或硬件拓扑无法唯一化时不自动猜测。
- 复用 Window Engine 已有 WinEvent 源监听原生移动开始、位置变化和移动结束；只有本次拖动观察到 Shift 才会在结束时吸附，没有新增轮询定时器或第二套系统 Hook。
- 高权限窗口不移动；停用 Window Engine 后控制器解除事件订阅，不再响应拖动。
- 壁纸组合支持建立空白档案并在独立编辑器内追加当前/已保存显示器、逻辑角色、壁纸和填充方式。空白组合不会匹配，未给所有角色选择有效托管壁纸时不能开启自动应用。

## 自动验证

- 窗口区域专用单元测试：10 个。
- 组合编辑专用单元测试：7 个。
- 原生集成测试：1 个，只创建和移动测试进程自己的临时窗口；当前 Windows 11 已通过 SetWindowPos、DWM 可见边框补偿和位置回读。
- 全套结果：181 个通过、0 个失败、2 个环境门禁测试按设计跳过。
- Release 构建：0 个警告、0 个错误。

覆盖项包括预设确定性、区域越界/重叠、竖屏主区、弱身份拒绝、相同路径歧义、负坐标与分辨率变化、高权限跳过、Shift 移动结束、无 Shift 不吸附、模块停止注销、空白组合不匹配、重复角色/显示器拒绝和自动应用完整性。

## 当前 Windows 11 资源样本

候选版主窗口保持可见时，10 秒空闲采样为：Working Set 236.1 MiB、Private Bytes 180.2 MiB、2693 个句柄、17 个线程、单核口径 CPU 0%。正式目录补齐全部发布运行时并以 `--background` 启动后的 10 秒空闲样本为：Working Set 170.0 MiB、Private Bytes 117.5 MiB、2092 个句柄、18 个线程、句柄净变化 -6、单核口径 CPU 0%。这些是当前三显示器 Windows 11 会话的短样本，不替代 30 分钟/12 小时稳态门禁。
