# 卸载

## EXE 安装版

打开 Windows“设置 → 应用”，找到“屏序 SyncWallpaper”，选择卸载。先保存正在编辑的组合并从托盘退出；卸载器发现安装目录中的程序仍在运行时会提示退出，不会强行结束程序。

卸载会移除本安装器登记的程序文件、卸载登记和快捷方式；只有仍指向本安装目录的屏序启动项才会被删除。卸载器依据安装时的文件清单清理，不会递归删除整个安装根目录；`Config`、`Wallpapers`、`Cache`、`Thumbnails`、`Logs` 和其他未登记的文件默认保留，外部数据目录也不会删除。应用内更新后新增且未被安装器登记的程序文件也可能保留，再次运行新版安装器可刷新清单。再次安装到同一目录即可继续使用保留的数据。

## ZIP 或脚本安装版

在原安装目录运行：

```powershell
.\uninstall.ps1
```

脚本会停止安装目录中的屏序程序，移除程序文件、当前用户启动项和屏序快捷方式。文件清理仅针对 `App`、`Diagnostics`、`docs` 和发行包根目录中已知的说明、图标、清单与安装脚本，不会递归删除整个安装目录。

安装目录里的 `Config`、`Wallpapers`、`Cache`、`Thumbnails`、`Logs` 以及其他非发行文件默认保留；旧的 `%LocalAppData%\SyncWallpaper` 数据目录也保留。`-KeepData` 继续可用，用于明确保留数据并省略保留提示；不传该参数或使用 `-KeepData:$false` 同样不会删除数据。

## 完全清理数据

安装器卸载与卸载脚本都不提供删除用户数据的选项。若需要完全清理，请先确认设置页显示的数据目录，退出程序并检查其中的内容，然后由你另行手动删除；不要将卸载正常完成理解为已经删除配置或壁纸。

卸载不会改变 Windows 显示参数或当前壁纸。
