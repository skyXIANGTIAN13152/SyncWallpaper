# 卸载

```powershell
.\uninstall.ps1
```

脚本会停止安装目录中的屏序程序，移除程序文件、当前用户启动项和屏序快捷方式。文件清理仅针对 `App`、`Diagnostics`、`docs` 和发行包根目录中已知的说明、图标、清单与安装脚本，不会递归删除整个安装目录。

安装目录里的 `Config`、`Wallpapers`、`Cache`、`Thumbnails`、`Logs` 以及其他非发行文件默认保留；旧的 `%LocalAppData%\SyncWallpaper` 数据目录也保留。`-KeepData` 继续可用，用于明确保留数据并省略保留提示；不传该参数或使用 `-KeepData:$false` 同样不会删除数据。

脚本没有删除用户数据的参数。若需要完全清理，请先确认设置页显示的数据目录，退出程序并检查其中的内容，然后由你另行手动删除；不要将卸载脚本的正常完成理解为已经删除配置或壁纸。

卸载不会改变 Windows 显示参数或当前壁纸。
