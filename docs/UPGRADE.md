# 升级

屏序只检查 GitHub Release，不自动下载、关闭程序、替换文件、运行安装器或回滚版本。

1. 从官方 Release 下载并校验 ZIP。
2. 从托盘退出屏序。
3. 将全新解压的发行包内容覆盖到原安装目录，包括 `App`、`Diagnostics`、说明文档和新版安装、升级、卸载脚本；不要先删除整个原目录。
4. 保留 `Config`、`Wallpapers`、`Cache`、`Thumbnails` 和 `Logs`。
5. 启动新版本，确认设置页显示正确数据目录和开机自启状态。

`upgrade.ps1` 使用同一安装脚本覆盖程序文件，不会删除运行数据。项目不创建更新 staging、更新备份或配置历史恢复点。

升级时使用全新解压的发行包作为来源，并先从托盘退出旧版本；脚本不会自动关闭正在运行的程序。默认脚本安装目录可在新发行包目录运行 `./upgrade.ps1 -PackagePath .`；脚本安装仅支持 `%LocalAppData%\Programs` 下的目标目录，其他解压位置按上述步骤覆盖发行文件。

1.2.0 会把旧特定组合迁移到 schema 6，并保留原有身份绑定。新通用组合包含旧版本不认识的字段，因此创建通用组合后不要让旧版本读写同一份配置；如需回退，请使用自行保存的升级前数据副本。
