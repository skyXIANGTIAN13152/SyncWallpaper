# Tray icon set

These resources are deliberately separate from the rich observing-eye artwork used inside the WPF window.

- `tray_normal`: cyan ring, monitor + companion laptop, stable status dot.
- `tray_paused`: gray-blue ring and a visible pause mark.
- `tray_recognizing`: broken scan ring and scan dots.
- `tray_error`: red broken ring, dashed uncertain display and warning triangle.

The runtime renderer in `SyncWallpaper.App` produces the same geometry as multi-frame 16/20/24/32/48/64 pixel ICO data. The SVGs are the reviewable source-of-truth for the icon language.
